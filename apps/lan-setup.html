🚀 Stamp Card — LAN Setup

Deine Rechner-IP (LAN)

Diese IP wird verwendet, um die Apps vom Smartphone aus zu erreichen:

Schritt 1: API starten

Auf deinem Computer (PowerShell):

cd D:\stamp
node api\server.cjs

Erwartet: 🚀 API listening on http://127.0.0.1:3000

Schritt 1b: Apps-Server starten

In einem **zweiten** Terminal (PowerShell):

cd D:\stamp
$env:PORT=8080; node apps\server.cjs

Erwartet: 📱 Apps Server running on http://localhost:8080 (wichtig: Port 8080 im LAN erreichbar)

Schritt 2: Apps öffnen

Auf deinem Computer (Desktop/Laptop):
  • Customer QR: http://localhost:8080/customer-qr.html
  • Café Scanner: http://localhost:8080/cafe-scanner.html
  • Café Issuer: http://localhost:8080/cafe-issuer-web.html
Auf deinem Smartphone (im gleichen WLAN):
  • Customer QR: http://:8080/customer-qr.html
  • Café Scanner: http://:8080/cafe-scanner.html
  • Café Issuer: http://:8080/cafe-issuer-web.html

Der Apps-Server läuft auf Port 8080. Die API läuft auf Port 3000.

Schritt 3: Flow testen

  1. Café Onboarding: Café registrieren oder einloggen
  2. Customer QR: QR anzeigen (Stempel oder Redeem, je nach Stand)
  3. Café Scanner: QR öffnen → Stempeln oder 🎁 Einlösen

💡 Tipps

  • IP ändern: Stelle sicher, dass dein Smartphone im gleichen WLAN wie dein Computer ist.
  • Firewall: Falls die Verbindung nicht funktioniert, prüfe deine Windows-Firewall (Port 3000 erlauben).
  • Zugang: Verwende E-Mail + Passwort (aus dem Café-Onboarding).
  • API verfügbar? Öffne http://:3000/health im Browser — sollte {"ok":true} zurückgeben.
