# Kaffeekarte Café App

Dieses Expo-Projekt ist der Startpunkt für die native Café App von Kaffeekarte.

Der Fokus dieser App:

- Betreiber-Login
- Scanner
- Stempel vergeben
- Rewards einlösen
- Basis-Profil für das Café

## Status

Aktuell ist dies noch ein Expo-Stub und noch keine produktfertige App.

Die übergeordnete Roadmap steht hier:

- [NATIVE_APP_PLAN.md](../../NATIVE_APP_PLAN.md)

## Lokaler Start

```bash
npm install
npx expo start
```
